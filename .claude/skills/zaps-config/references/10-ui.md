# UI Config — `ui` Block

TUI-local presentation. The whole block is optional and every field has a safe
default, so omitting `ui` (or any field) resolves to the defaults below.

## UiConfig Type

```ts
export type UiIconTheme = "nerd" | "unicode" | "ascii";
export type UiNotifications = "off" | "bell" | "osc9" | "osc9+bell";
export type UiFailOutput = "overlay" | "popup";
export type UiTaskMode = "background" | "pane";

export interface UiTaskConfig {
  defaultMode?: UiTaskMode; // default "background"
  popupPicker?: boolean; // default false
}

export interface UiConfig {
  icons?: UiIconTheme; // default "nerd"
  notifications?: UiNotifications; // default "osc9"
  failOutput?: UiFailOutput; // default "overlay"
  task?: UiTaskConfig;
  wideThreshold?: number; // integer ≥ 40, default 100
}
```

## Fields

| Field              | Values                                     | Default        | Description                                                                         |
| ------------------ | ------------------------------------------ | -------------- | ----------------------------------------------------------------------------------- |
| `icons`            | `"nerd" \| "unicode" \| "ascii"`           | `"nerd"`       | Glyph tier. The `ZAPS_ICONS` env var overrides the config value at startup.         |
| `notifications`    | `"off" \| "bell" \| "osc9" \| "osc9+bell"` | `"osc9"`       | Out-of-band failure notification channel (OSC 9 desktop notification / bell).       |
| `failOutput`       | `"overlay" \| "popup"`                     | `"overlay"`    | Where the `f` failed-output view opens; `popup` escalates straight to a tmux popup. |
| `task.defaultMode` | `"background" \| "pane"`                   | `"background"` | Mode for `Enter` in the task picker. `Tab` always runs in a pane.                   |
| `task.popupPicker` | `boolean`                                  | `false`        | Use an `fzf` tmux popup picker instead of the in-app one.                           |
| `wideThreshold`    | `number` (integer ≥ 40)                    | `100`          | Minimum terminal columns to show the detail pane; below it the pane collapses.      |

## Notes

- **`notifications`** fires on **task failure** only: `bell` rings the terminal
  bell, `osc9` emits an OSC 9 desktop notification, `osc9+bell` does both, `off`
  disables it. Only the task name is emitted — never log/output content.
- **`task.popupPicker`** falls back to the in-app picker when tmux is older than
  3.2 or `fzf` is not on `PATH`.
- **`wideThreshold`** has a hard floor of 40 in the schema; a value below the
  practical split minimum still collapses the detail pane.

## Example

```ts
ui: {
  icons: "unicode",
  notifications: "osc9+bell",
  failOutput: "popup",
  wideThreshold: 120,
  task: { defaultMode: "pane", popupPicker: true },
}
```
